# Cadence

Application web (PWA) : agenda de séances de sport, tâches avec rappels, calcul des macros, plans de repas, liste de courses, suivi du poids et journal alimentaire (photo IA avec Gemini, code-barres avec Open Food Facts).

Installation sur iPhone : ouvre https://zypnozz.github.io/cadence/ dans Safari, touche Partager puis « Sur l'écran d'accueil ».

Toutes les données restent sur l'appareil de chaque utilisateur. Voir les conditions d'utilisation et la politique de confidentialité dans l'application.
